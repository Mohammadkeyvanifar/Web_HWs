# تمرین عملی HTTP - مهندسی اینترنت

**نام و شماره دانشجویی:** محمد کیوانی فر (40231421)

## بخش اول: سوالات تئوری

### ۱. چگونه سرویس را فقط روی شبکه داخلی اجرا کنیم؟
**جواب:** سرویس را به جای `0.0.0.0` (همه اینترفیس‌ها) به `127.0.0.1` (لوکال‌هاست) یا به IP داخلی سرور (مثلاً `192.168.x.x`) بایند کنید. در کد پایتون، `HOST = "0.0.0.0"` را به `HOST = "127.0.0.1"` تغییر دهید. همچنین در فایروال/سکیوریتی‌گروپ، پورت مربوطه را فقط برای subnet داخلی باز کنید و دسترسی از اینترنت را ببندید.

### ۲. فلسفه TLS Termination
**جواب:** در معماری reverse proxy، سرویس داخلی (legacy) معمولاً قدیمی است و از TLS پشتیبانی نمی‌کند یا مدیریت گواهی برایش دردسر دارد. با **TLS Termination**، لایه رمزنگاری در پروکسی (که در لبه شبکه است) خاتمه می‌یابد: پروکسی گواهی و handshake را مدیریت می‌کند، ترافیک را رمزگشایی می‌کند و سپس به صورت HTTP ساده (یا رمزنگاری‌شده مجدد) به سرویس داخلی می‌فرستد. مزیت: سرویس داخلی بدون تغییر امن می‌شود، مدیریت گواهی متمرکز می‌شود، و بار رمزنگاری از دوش سرویس قدیمی برداشته می‌شود.

### ۳. پروژه JWT Proxy با Go-httpbin
**جواب:** یک لایه پروکسی (مثلاً با Nginx، Envoy یا یک پروکسی Go) جلوی `go-httpbin` قرار می‌دهید. پروکسی درخواست‌ها را بررسی می‌کند: اگر هدر `Authorization: Bearer <token>` وجود داشت و JWT معتبر بود (امضا، انقضا، issuer/audience)، درخواست را به `go-httpbin` فوروارد می‌کند؛ در غیر این صورت `401 Unauthorized` برمی‌گرداند. برای اجرا: `docker run -p 8080:8080 mccutchen/go-httpbin` و سپس پروکسی را روی پورت دیگری (مثلاً `8888`) تنظیم کنید که به `http://127.0.0.1:8080` فوروارد کند.
